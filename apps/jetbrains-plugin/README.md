# CodeAtlas JetBrains Plugin

Official CodeAtlas plugin for IntelliJ IDEA, WebStorm, PyCharm, and other JetBrains IDEs.

## 🚀 Features

- **One-click indexing**: Integrates directly into IDE Tools menu.
- **Architecture diagnostics**: Circular dependency and dead code analysis.
- **Natural language graph queries**: Query your project structure in plain English.
